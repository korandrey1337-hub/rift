# Capsule Rift

A small browser gacha arena prototype.

## Play

Open `index.html` directly, or serve the folder with any static web server.

## Current loop

- Pull capsules with coins.
- Unlock heroes or convert duplicates into shards.
- Pick an unlocked hero.
- Clear short arena runs for coins and shards.
- Progress through harder stages.

## Controls

- Move: WASD or arrow keys.
- Aim: pointer over the arena.
- Ultimate: Space or the Ultimate button.
